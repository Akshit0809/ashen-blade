# ⚔️ ASHEN BLADE — Director's Cut (3D Browser Boss Duel)

A self-contained 3D anime boss-duel action game built entirely with **Three.js**, **UnrealBloomPass**, **Vanilla CSS**, and **Procedural Web Audio Synthesis** (zero external 3D models, textures, or audio files).

## 🎮 Playable Characters (`[TAB]` to Switch Anytime)
* **Toji Fushiguro** — *The Sorcerer Killer* (Inverted Spear of Heaven, Coiled Inventory Curse, Chain of a Thousand Miles)
* **Son Goku (SSJ)** — *Super Saiyan Legend* (Kamehameha Beam, Instant Transmission, Kaioken Shield, Super Spirit Bomb)
* **Satoru Gojo** — *The Honored One* (Black Flash, Lapse: Blue, Reversal: Red, Hollow Technique: Purple)

## 🐉 Boss: Kagu-Ryu, Ancient Storm Dragon
* **Phase I — Special-Grade Awakening**: Coiling storm lightning, sweeping lunges, and deflectable fireballs.
* **Phase II — Abyssal Void Nightmare (1.5x HP)**: Mutates into an Abyssal Calamity with 6 eyes, a spinning Void Halo, meteor storms, and sweeping plasma breath beams.

## 🕹️ Controls
| Input | Action |
| :--- | :--- |
| **WASD** | Move Character |
| **Mouse** | Over-the-Shoulder Aim & Camera |
| **Left Click** | 3-Hit Signature Combo |
| **Right Click** | Timed Deflect / Parry Projectiles |
| **Space** | High-Speed Flash Step / Dodge |
| **1 / 2 / 3 / 4** | Cast Signature Anime Techniques & Ultimates |
| **TAB** | Switch Playable Fighter (Toji / Goku / Gojo) |
| **C** | Replay 15-Second 4-Act Story Cutscene |
